CLI do BR Panel

Tudo o que o painel faz pode ser feito no terminal do servidor com o comando brpanel: publicar apps, ver logs, mudar variáveis, domínios, bancos de dados e backups. São {{.CLICount}} comandos, com respostas curtas e iguais em todos eles, pensados para pessoas e para agentes de IA.

sudo brpanel status
sudo brpanel apps list
sudo brpanel apps deploy minha-app --wait

O comando fala com o painel por um socket local (/var/lib/brpanel/brpanel.sock) que só o root abre. Não há senha, token nem variável de ambiente para configurar, e nada fica exposto na rede. Se a pasta de dados não for a padrão, use --data PASTA.

Para agentes de IA

Cole este bloco no prompt do sistema de qualquer agente. Ele funciona até com modelos pequenos (4B): são poucas regras, e cada resposta do comando começa com OK: ou ERRO: e traz linhas DICA: com o próximo passo. Erros de digitação sugerem o comando certo (você quis dizer…).

O guia completo (brpanel guide) traz receitas passo a passo e uma tabela de erros. Para um agente que lê arquivos, salve-o como AGENTS.md ou CLAUDE.md do projeto.

Como as respostas funcionam

OK: …
deu certo (código de saída 0)
ERRO: …
falhou: código 1 se o painel recusou, 2 se o comando foi escrito errado
DICA: …
o próximo passo; USO: e EXEMPLO: mostram a forma certa
--json
qualquer comando responde em JSON
--yes
obrigatório nos comandos que apagam dados; sem ele nada é apagado
--wait
o deploy roda em segundo plano; com --wait o comando espera e diz se deu certo
