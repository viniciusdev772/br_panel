Criar GitHub App

  1. Clique em Continuar no GitHub. O painel envia o formulário do App já preenchido (webhook de push e permissão Contents: read-only).
  2. No GitHub, confira o nome (ele precisa ser único; pode trocar) e confirme com Create GitHub App.
  3. O GitHub devolve você ao painel, que guarda o App ID, a chave privada e o segredo do webhook sozinho.
  4. Por fim, instale o App nos repositórios desejados e marque Deploy automático na aplicação.

O App é criado na conta do GitHub em que você estiver logado. Este pedido vale por 15 minutos.
