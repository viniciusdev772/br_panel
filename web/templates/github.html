Como configurar

  1. No GitHub: Settings → Developer settings → GitHub Apps → New GitHub App.
  2. Webhook URL: {{.GH.WebhookURL}} (precisa ser HTTPS público; defina PANEL_DOMAIN para o painel ganhar Nginx + SSL). Content type: application/json.
  3. Defina um Webhook secret e exporte o mesmo valor em PANEL_GITHUB_WEBHOOK_SECRET.
  4. Permissions → Repository: Contents: Read-only (Metadata é incluída automaticamente). Subscribe to events: Push.
  5. Gere uma private key (.pem), salve no servidor e informe PANEL_GITHUB_APP_ID e PANEL_GITHUB_KEY_FILE — usado para clonar repositórios privados com um token de 1 hora, somente leitura.
  6. Install App nos repositórios desejados e marque Deploy automático na aplicação.

Cada push na branch configurada dispara um deploy; pushes recebidos durante um deploy geram uma nova execução ao final.
