Configuração manual

  1. No GitHub: Settings → Developer settings → GitHub Apps → New GitHub App.
  2. Webhook URL: {{.GH.WebhookURL}} (precisa ser HTTPS público; informe um domínio para o painel em Configurações para ele ganhar Nginx + SSL). Content type: application/json.
  3. Defina um Webhook secret e salve o mesmo valor em Configurações.
  4. Permissions → Repository: Contents: Read-only (Metadata é incluída automaticamente). Subscribe to events: Push.
  5. Gere uma private key (.pem), cole o conteúdo e o App ID em Configurações — usado para clonar repositórios privados com um token de 1 hora, somente leitura.
  6. Install App nos repositórios desejados e marque Deploy automático na aplicação.

Cada push na branch configurada dispara um deploy; pushes recebidos durante um deploy geram uma nova execução ao final.
